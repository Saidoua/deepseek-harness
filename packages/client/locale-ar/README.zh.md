# @deepseek-ai/dsh-client-locale-ar

[English](README.md) | 中文

## 概述

`dsh-client-locale-ar` 为 Web GUI 添加阿拉伯语。它以英语为回退、以从右到左为阅读顺序注册 `ar` 语言，然后为已发布的客户端包声明的每个命名空间各注册一份词典。用户在 设置 → 通用 中选择它；界面文案立即切换，被标记的文本区域按从右到左阅读，而应用框架保持原位。该包只贡献翻译与阅读顺序：它不挂载任何界面，不读取设置，也不持有状态。

<a id="use-this-package"></a>
## 使用本包

该包随 `web` profile 一同发布，因此阿拉伯语会与中文、英文一起出现在 设置 → 通用 中，无需任何配置。选择它会一次性切换所有已翻译的界面，并像其他语言偏好一样保存选择。

### 启用阿拉伯语后有什么变化

产品文案跟随语言：按钮、标签、描述、占位符、无障碍名称与状态文本都以阿拉伯语显示，并在每个被标记的文本区域内向阅读起始边对齐。应用框架不会移动——侧边栏保持其位置与宽度，工具栏与控件保持原位。

非产品文案的文本保留自身方向。你与模型撰写的消息带有 `dir="auto"`，因此阿拉伯语界面中的英文回复仍从左到右阅读，混合语言的对话也能逐行正确显示。代码、终端输出、diff、文件内容与结构化数据始终从左到右渲染，因为列序是其含义的一部分。

### 读取没有阿拉伯语文本的键

该语言声明英语为回退，因此本包尚未翻译的键会显示英文而不是裸键。对于所有导出键联合类型的命名空间，这种情况是构建错误：当上游包新增一个键却没有阿拉伯语对应项时，本包的类型检查会失败。唯一不在该保证之内的命名空间是 `directory-browser`，其所有者在插件体内内联声明词典。

### 添加你自己的语言

本包是 [locale 包](../locale/README.zh.md#use-this-package) 所述语言包约定的完整示例：把语言定义和每个命名空间注册为自身拥有的 effect，声明一条终止于英语的回退链，并在语言定义上声明阅读顺序，而不是直接改动文档。

## 理解实现

<details>
<summary>实现内幕 —— 点击展开</summary>

### 设计理念

插件体就是一个循环。它先添加语言，这样即使后续某份词典注册失败，留下的也是一个可选择、回退到英语的语言，而不是无法被选中的词典；随后从一张冻结的表中注册每个命名空间。每次注册都是 `ctx.effect`，因此卸载插件会一并移除语言与其文案，并把生效中的阿拉伯语选择退回到一个可用语言。

每个词典文件都以 `satisfies Record<XxxKey, string>` 对照其所有者包通过 `./src/*` 子路径导出的键联合类型进行声明，并以仅类型方式导入。因此完整性是本包的编译期属性，而不是运行时扫描。类型无法检查的是词典注册所用的命名空间 *id*，因为拼写错误会产生一次无人读取的合法注册；本包的规范通过为每个命名空间族翻译一个键来固定这些 id。

### 翻译决策

[`locales/glossary.ts`](src/client/locales/glossary.ts) 固定反复出现的产品术语，使同一个概念不会出现两个名称。标识符保持原样：模型 id、提供方名称、工具名称、包名、斜杠命令、文件格式、协议名称、键盘上印刷的按键名，以及字面示例值。翻译它们会让其无法被检索，对命令而言还会无法输入。

计数措辞与数量无关。阿拉伯语区分六种复数类别，而 locale 运行时只对扁平模板插值、不做复数选择，因此命名空间的 `.one` 与 `.other` 键承载同一句阿拉伯语，其措辞在任何数量下都能正确阅读。数字保持西方数字，与运行时插入的数值一致。

## 模型体验

无，本包是浏览器端的词典注册表，不注册任何面向模型的内容。

#### KV Cache effect

无；本包既不组装也不发送提供方请求。

## 已知限制与延期工作

<a id="known-limitations-and-deferred-work"></a>


这些限制说明阿拉伯语界面在哪些地方尚不完整。它们是当前包约束，不是任务积压。

- **没有复数一致性**——运行时不选择复数类别，因此带数量的句子采用在任何数量下都可接受的措辞，而不是与其数字保持一致。加入复数规则属于 locale 运行时改动，而非词典改动。
- **`directory-browser` 没有编译期完整性检查**——其所有者内联声明词典而不导出键联合类型，因此在那里新增的键会静默回退到英语。
- **注册时捕获的文案保持其语言**——locale 服务的[注册表持有文本限制](../locale/README.zh.md#known-limitations-and-deferred-work)原样适用于本包。
- **不随附阿拉伯语网络字体**——本包不向字体栈追加任何内容，依赖平台提供的系统阿拉伯语字体族。

### 开发备注

当上游包新增一个文案键时，失败的会是本包的类型检查。请在同一次变更中在此翻译该键，而不是放宽 `satisfies` 子句。

**Runtime invariant:** 不发布伴生实现。本包没有可供比对的独立运行时关系：注册、卸载与回退都是 locale 服务的行为，而本包的规范直接断言它自己的命名空间 id 与语言定义。
